A1Mission Logs · Open a file 10 min

  
Three ways to open a file

  
open() needs a filename and a mode. The mode decides what you're allowed to do, and one of them can wipe your file.

  

    
ModeNameIf the file existsIf the file doesn't exist

    
      
"r"ReadReads it from the startFileNotFoundError crash

      
"w"WriteWipes it, then writes from emptyCreates it

      
"a"AppendAdds to the end and keeps everythingCreates it

    


# Write two lines (this creates or WIPES mission_log.txt)
with open("mission_log.txt", "w") as file:
    file.write("Desk started\n")
    file.write("Nova reported for duty\n")

# Add one more line to the end
with open("mission_log.txt", "a") as file:
    file.write("Kai reported for duty\n")

# Read the whole file back
with open("mission_log.txt", "r") as file:
    print(file.read())


Desk started
Nova reported for duty
Kai reported for duty

  
Why with? The indented block uses the file, and when the block ends Python closes the file for you, even if an error happens. Without with you must call file.close() yourself, and an unclosed file may not save everything.

  
"\n" matters. write() does not start a new line for you. Forget "\n" and every record lands on one long line.

  






  
A2Mission Logs · Save and load the roster 15 min

  
Turn dictionaries into lines, and lines back into dictionaries

  
A file only stores text. To save a cadet we turn the dictionary into one line of text with commas between the values. To load, we reverse every step.


  

    
in memory{"name": "Nova", "squad": "Falcon", "score": 88}

    
save: f-string + "\n" →

    
in roster.txtNova,Falcon,88\n

    
load: strip() → split(",") → int() →

    
back in memory{"name": "Nova", "squad": "Falcon", "score": 88}

Save: one line per cadet


def save_roster(roster, filename):
    with open(filename, "w") as file:
        for cadet in roster:
            file.write(f"{cadet['name']},{cadet['squad']},{cadet['score']}\n")

save_roster(roster, "roster.txt")


roster.txt now contains:
Nova,Falcon,88
Kai,Viper,74
Mira,Falcon,91
Jett,Orca,65


  
Load: reverse every step


def load_roster(filename):
    roster = []
    with open(filename, "r") as file:
        for line in file:
            line = line.strip()            # "Nova,Falcon,88\n" -> "Nova,Falcon,88"
            parts = line.split(",")        # -> ["Nova", "Falcon", "88"]
            cadet = {"name": parts[0],
                     "squad": parts[1],
                     "score": int(parts[2])}   # "88" -> 88
            roster.append(cadet)
    return roster

roster = load_roster("roster.txt")
print(roster[0])


{'name': 'Nova', 'squad': 'Falcon', 'score': 88}

  
Why int()? Everything read from a file is a string. Without int(), "88" + 1 crashes and "9" > "10" is True.

A3Mission Logs · Keep a log 10 min

  
A log that only grows

  
The roster is rewritten every save, so it uses "w". A mission log keeps every event forever, so it uses "a".


def log_event(message):
    with open("mission_log.txt", "a") as file:
        file.write(message + "\n")

log_event("Desk started")
log_event("Roster loaded")
log_event("Zara added to Falcon")

B1Corrupted Records · Crash gallery 8 min

  
Name the crash before it happens

  
When Python can't do something it raises an exception. If nothing catches it, the program stops with a red traceback. These are the three you'll meet at the Records Desk.

  

    
FileNotFoundError
Opening a file in "r" mode that doesn't exist.

    
ValueError
Right type, wrong value: int("seventy-four").

    
IndexError
Asking for a position that isn't there: parts[2] when there are only 2 parts.

  

  
Try them in the simulator: with the shield off, delete the file and press Load, or type seventy as a score.

  






  
B2Corrupted Records · try / except 12 min

  
Catch the error and keep the desk running

  
Put risky code in a try block. If it raises the error named in except, Python jumps there instead of crashing.


# 1. A missing file: start with an empty roster instead of crashing
try:
    roster = load_roster("roster.txt")
except FileNotFoundError:
    print("No saved roster yet. Starting fresh.")
    roster = []

# 2. Bad typing: ask again instead of crashing
while True:
    try:
        score = int(input("Score: "))
        break                      # only reached if int() worked
    except ValueError:
        print("Score must be a whole number, like 79.")

  

    
PartRuns when…

    
      
try:Always: the risky code

      
except ValueError:Only if that error happened in try

      
except (IndexError, ValueError) as error:Either error; error holds the details

      
else:Only if try had no error

      
finally:Always, error or not (good for "Desk closed" messages)

    

  
Name the error. A bare except: catches everything, including your own typos, so real bugs disappear silently. Always say which errors you expect.
