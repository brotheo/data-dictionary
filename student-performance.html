02Mission 1 · Filter the evidence 15 min

Pull out only the rows that matter

A filter is a question with a yes/no answer for every row. pandas checks the condition on all 20 rows at once and keeps the True ones.

1.1 One condition

high_scores = df.loc[df["Score"] > 80]
display(high_scores[["Name", "Subject", "Score"]])

Say it out loud: "From df, locate the rows where Score is greater than 80." You should get 10 students.

1.2 AND: both must be true

# Year 10 AND score of at least 80
year10_high = df.loc[(df["Year"] == 10) & (df["Score"] >= 80)]
display(year10_high[["Name", "Year", "Subject", "Score"]])
Alex 85, Lily 90, Sofia 87

1.3 OR: either can be true

# Attendance below 80% OR score below 60
needs_attention = df.loc[(df["Attendance"] < 80) | (df["Score"] < 60)]
display(needs_attention[["Name", "Score", "Attendance"]])
Fiona 56/78%, Marcus 48/72%, Thomas 58/76%
The two rules that cause most errors: use & and |, never and / or, and wrap every condition in its own brackets. Without brackets Python works out 10 & df["Score"] first and crashes.

1.4 Rows and columns together

computing = df.loc[df["Subject"] == "Computing", ["Name", "Score", "Attendance"]]
display(computing)

bands = pd.cut(df["Attendance"], bins=[0, 79.99, 89.99, 100],
               labels=["Below 80%", "80–89%", "90–100%"])

attendance_summary = (
    df.assign(Band=bands)
      .groupby("Band", observed=False)

      .round(2)

Students Average_Score Below 80% 3 54.00 80–89% 5 69.40 90–100% 12 86.75

3.4 Study hours and score

r = df["Study_Hours"].corr(df["Score"])   # between -1 and +1
print("Correlation:", round(r, 2))

study_summary = (
    df.assign(Study_Group=pd.cut(df["Study_Hours"], bins=[0, 4, 8, 20],
                                 labels=["1–4 h", "5–8 h", "9+ h"]))
      .groupby("Study_Group", observed=False)
      .agg(Students=("Student_ID", "count"), Average_Score=("Score", "mean"))
      .round(2)
)
display(study_summary)
Correlation: 0.96 Students Average_Score 1–4 h 4 56.25 5–8 h 7 74.43 9+ h 9 89.33

We use assign() so the extra column lives only in the result and df stays at 8 columns.

Correlation ≠ cause. A value of 0.96 means study hours and score rise together in this dataset. It doesn't prove that studying causes the higher score. Attendance rises with them too (correlation 0.99), and any of the three could be driven by something we haven't measured.
PLOT TWIST

Is Mathematics really the easiest subject?

Mathematics has the highest average (84). Before you say "Maths is easy", run this:

display(pd.crosstab(df["Year"], df["Subject"]))
Subject Computing Mathematics Science Year 9 6 0 0 10 1 0 6 11 0 7 0

Every Mathematics student is in Year 11, and every Year 11 student took Mathematics. Year and subject are confounded: tangled together so tightly that we can't tell whether the high average comes from the subject, from being older, or from both. A good analyst says so instead of guessing.

3.5 Reusable analysis functions

def show_top_students(data, number=5):
    """Return the highest-scoring rows."""
    return data.sort_values("Score", ascending=False).head(number)

def average_score(data, subject=None):
    """Overall average, or the average for one subject (None if it doesn't exist)."""
    rows = data if subject is None else data.loc[data["Subject"] == subject]
    if rows.empty:
        return None
    return round(rows["Score"].mean(), 2)

print(average_score(df))               # 77.5
print(average_score(df, "Computing"))  # 73.43
print(average_score(df, "Art"))        # None

00Briefing · The evidence 6 min

The data dictionary

A data dictionary is the rulebook for a dataset. It lists every column, its data type, what it means and which values are allowed. Analysts use it to spot records that break the rules before they calculate anything.

ColumnTypeMeaningRules
Order_IDintReceipt numberUnique: each order appears once
DaystrSchool day of the sale"Mon", "Tue", "Wed", "Thu" or "Fri"
ItemstrProduct soldMust exactly match a key in prices (capital letters count)
QuantityintUnits in the orderWhole number from 1 to 10
Year_GroupintBuyer's year group9, 10 or 11 only (the tuck shop serves lower school)
PaymentstrHow the order was paid"Cash" or "Card"
PricefloatPrice per unit ($)Not in the raw data. Create it from the prices dictionary
CategorystrSnack, Drink or MealNot in the raw data. Create it from the categories dictionary
RevenuefloatMoney from the order ($)Not in the raw data. Price × Quantity

def item_report(data, item):
    rows = data.loc[data["Item"] == item]
    return {
        "item": item,
        "orders": len(rows),
        "quantity": int(rows["Quantity"].sum()),
        "revenue": round(float(rows["Revenue"].sum()), 2)
    }

def daily_totals(data):
    totals = {}
    for day in ["Mon", "Tue", "Wed", "Thu", "Fri"]:
        totals[day] = round(float(data.loc[data["Day"] == day, "Revenue"].sum()), 2)
    return totals

print(item_report(df, "Cookie"))
totals = daily_totals(df)
print(totals)

best_day = max(totals, key=totals.get)
print("Best day:", best_day)
