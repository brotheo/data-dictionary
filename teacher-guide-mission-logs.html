Learning objectives

  • Open files in read, write and append mode using with
  • Save a list of dictionaries as comma-separated lines, and load it back
  • Name and predict FileNotFoundError, ValueError and IndexError
  • Use try/except so one bad record or a missing file doesn't crash the program

Success criteria

  • Worksheet A reloads 5 cadets
  • Worksheet B loads 3 cadets and reports 4 damaged lines
  • Explains why the try goes inside the loop
  • Explains the difference between "w" and "a"

Before the lesson

  • In Colab, files appear in the folder panel on the left and disappear when the runtime resets. That's a good demonstration of "the disk" being part of the machine.
  • In IDLE, files are saved next to the .py file. Students running from different folders may get FileNotFoundError: that's on-topic.
  • The Boss level uses input() in a loop. It works in Colab and IDLE; some online editors handle input() poorly.
  • XP is stored in the browser only. The simulator works offline once the page is open.

Worksheet A solution

Assumes the starting roster cell (4 cadets) was run first.

def save_roster(roster, filename):
    with open(filename, "w") as file:
        for cadet in roster:
            file.write(f"{cadet['name']},{cadet['squad']},{cadet['score']}\n")


def load_roster(filename):
    roster = []
    with open(filename, "r") as file:
        for line in file:
            line = line.strip()
            parts = line.split(",")
            cadet = {"name": parts[0], "squad": parts[1], "score": int(parts[2])}
            roster.append(cadet)
    return roster


def log_event(message):
    with open("mission_log.txt", "a") as file:
        file.write(message + "\n")


roster.append({"name": "Zara", "squad": "Falcon", "score": 79})
save_roster(roster, "roster.txt")
log_event("Zara added and roster saved")

reloaded = load_roster("roster.txt")
print("Cadets after reload:", len(reloaded))
print("Last cadet:", reloaded[-1])

Worksheet B solution

def load_roster(filename):
    roster = []
    damaged = 0
    try:
        with open(filename, "r") as file:
            line_number = 0
            for line in file:
                line_number += 1
                line = line.strip()
                if line == "":
                    continue

                try:
                    parts = line.split(",")
                    cadet = {"name": parts[0], "squad": parts[1], "score": int(parts[2])}
                    roster.append(cadet)
                except (IndexError, ValueError) as error:
                    damaged += 1
                    print("Line", line_number, "damaged:", line, "->", type(error).__name__)

    except FileNotFoundError:
        print("No file called", filename, "- starting with an empty roster.")

    print("Loaded", len(roster), "cadets,", damaged, "damaged lines skipped.")
    return roster


good = load_roster("roster_damaged.txt")
print([cadet["name"] for cadet in good])
nothing = load_roster("ghost.txt")

Accept except ValueError: and except IndexError: as two separate blocks. If he gets 1 cadet, the inner try is missing; 0 cadets plus the "No file" message means roster_damaged.txt wasn't created.

Boss level · Records Desk solution

Needs save_roster and log_event from Worksheet A and load_roster from Worksheet B above it.

FILENAME = "roster.txt"
roster = load_roster(FILENAME)
log_event("Desk started")

while True:
    print("\n=== ACADEMY RECORDS DESK ===")
    print("1. Show roster   2. Add cadet   3. Save   4. Save and quit")
    choice = input("Choose 1-4: ")

    if choice == "1":
        for cadet in roster:
            print(cadet["name"], "|", cadet["squad"], "|", cadet["score"])

    elif choice == "2":
        name = input("Name: ")
        squad = input("Squad: ")
        try:
            score = int(input("Score: "))
        except ValueError:
            print("Score must be a whole number. Cadet not added.")
        else:
            roster.append({"name": name, "squad": squad, "score": score})
            log_event("Added " + name)
            print(name, "added.")

    elif choice == "3":
        save_roster(roster, FILENAME)
        log_event("Roster saved")

    elif choice == "4":
        save_roster(roster, FILENAME)
        log_event("Desk closed")
        print("Roster saved. Goodbye, Commander.")
        break

    else:
        print("Unknown option. Type 1, 2, 3 or 4.")
